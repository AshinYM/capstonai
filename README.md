# 다시봄 · 수업 복습 에이전트

수업 녹취록과 교안을 등록하고 요약·질문·복습을 한 화면에서 진행하는 개인용 미니 프로젝트입니다.

## 빠른 실행 (macOS / Linux, Python 3.11 이상)

```bash
bash scripts/setup.sh
bash scripts/run.sh
```

브라우저: http://127.0.0.1:8600

이미 전용 `.venv`가 준비된 이 컴퓨터에서는 `bash scripts/run.sh`만 실행합니다. 종료는 실행 중인 터미널에서 Ctrl+C입니다. 포트가 사용 중이면 `PORT=8601 bash scripts/run.sh`로 다른 포트를 선택하세요.

Windows PowerShell:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
Copy-Item .env.example .env  # 최초 1회만, 기존 .env가 있으면 생략
.\.venv\Scripts\python.exe -m uvicorn server:app --host 127.0.0.1 --port 8600
```

## 사용 순서

1. 자료 추가에서 TXT·MD·PDF를 등록하거나 수업 내용을 붙여넣습니다.
2. 왼쪽 체크박스로 복습할 자료를 선택합니다(최대 20개).
3. 핵심 요약, 복습 퀴즈 또는 직접 질문을 사용합니다.
4. 답변 아래의 자료 이름을 누르면 PDF 페이지 또는 텍스트 행 번호와 원문을 확인할 수 있습니다.
5. 같은 브라우저에서는 새로고침·서버 재시작 후에도 현재 대화가 유지됩니다. 새 대화 버튼은 새 세션을 만듭니다. 과거 세션 목록을 탐색하는 UI는 아직 없습니다.

`sample_data/수업예시.txt`는 직접 작성한 기능 확인용 자료입니다. 사용자의 원본 강의 자료를 자동으로 가져오거나 외부로 전송하지 않습니다.

## 실행 모드와 API 종류

`.env.example`을 `.env`로 복사한 후 설정합니다. 설정 변경 후 서버를 다시 시작합니다.

| LLM_BACKEND | 역할 | 필요한 것 |
|---|---|---|
| extractive | 검색된 원문 발췌, 요약용 구간 선택, 원문 설명 연습 질문 | 없음. 기본 모드이며 AI 생성 요약이 아닙니다. |
| ollama | 근거를 바탕으로 AI 요약·답변·정답 포함 퀴즈 작성 | 실행 중인 Ollama, 설치한 모델 이름. API 키 불필요 |
| openai | 같은 작업을 OpenAI Responses API로 생성 | OPENAI_API_KEY, 사용 가능한 OPENAI_MODEL. 호출 비용 발생 |

Ollama 예시: `LLM_BACKEND=ollama`, `OLLAMA_MODEL=qwen3:8b`. 모델이 없다면 Ollama에서 별도로 준비해야 합니다. 이 프로젝트 설치 스크립트는 대형 모델을 자동 다운로드하지 않습니다.
OpenAI 예시: `LLM_BACKEND=openai`, `OPENAI_MODEL=gpt-4o-mini`, `OPENAI_API_KEY=본인키`.
모델명은 계정·로컬 설치 상황에 맞게 바꿀 수 있습니다. AI 모드에서는 선택된 근거 구간과 최근 대화 일부가 해당 모델로 전달됩니다. 원문 발췌 모드에는 모델 호출이 없습니다.
API 키는 Git에 올리지 않습니다. `.env`는 `.gitignore`에 포함되어 있습니다. 키를 화면에 입력받거나 응답에 포함하는 기능은 없습니다.

## 구현 구조

```text
server.py              FastAPI API 및 앱 수명 동안 의존성 생성
review/documents.py    파일 읽기, PDF 페이지/텍스트 행 위치 유지, 청킹
review/storage.py      SQLite 자료·구간·대화 저장
review/retrieval.py    BM25 방식 어휘 검색 + 한국어 문자 바이그램
review/summary.py      전체 구간 분할 요약·계층 통합·원문 출처 연결·부분 캐시
review/model.py        Ollama / OpenAI 모델 어댑터
review/graph.py        라우팅 → 검색 → 작성 → 출처 검사 → 종료
web/                   외부 CDN 없는 HTML/CSS/JavaScript 화면
sample_data/           직접 작성한 예제
reference/base_agent/  제공된 원본 실습 소스 보관(수정하지 않음)
```

원본의 FastAPI·LangGraph·라우팅·세션·의존성 분리·검증 후 재시도 패턴을 참고하여 새 주제의 앱을 구현했습니다. 원본 장애 대응 코드에 수업 자료를 억지로 매핑하지 않고 수업 전용 모듈을 작성했습니다. 화면도 별도 빌드/CDN 없이 실행되는 JavaScript로 새로 작성했습니다.

이 버전은 단일 LangGraph 워크플로입니다. 여러 독립 에이전트가 협업하는 Multi-Agent, MCP 연동, 벡터 DB·임베딩 검색은 아직 구현하지 않았습니다. 어휘 기반 검색 결과를 모델에 제공하므로 AI 모드에서는 검색 증강 생성 방식으로 동작합니다.

Ollama와 OpenAI 모두 답변 본문과 사용한 출처 번호를 구조화된 JSON으로 받도록 요청하며, 퀴즈는 질문·정답·해설 3세트의 고정 구조를 사용합니다. 모델이 선택한 유효한 출처 번호만 실제 구간 ID로 연결합니다. 검증 노드는 인용 ID가 제공된 구간에 속하는지와 AI 퀴즈의 3문항·정답·해설 형식을 확인하고 실패하면 최대 한 번 재작성합니다. 두 번 모두 실패하면 원문을 대신 반환합니다. 모델 연결 실패는 503으로 표시하며 성공한 것처럼 발췌 결과로 조용히 바꾸지 않습니다. 인용의 존재는 문장 내용의 사실성을 보장하지 않으므로 원문을 확인해야 합니다.

## 테스트

```bash
.venv/bin/python -m pytest -q
```

Windows: `.\.venv\Scripts\python.exe -m pytest -q`

자료 격리, 관련 없는 질문의 근거 부족 응답, 중복 업로드, 삭제한 자료 선택, 인코딩, 빈/손상/스캔 PDF, 용량 제한, 재시작 후 기록, 출처 오류 재시도, 모델 연결 실패 등을 검사합니다. 테스트에서 모델을 모의 호출하며 실제 API 요금을 발생시키지 않습니다. 실제 수업 자료와 다른 모델의 응답 품질은 추가 검증해야 합니다. 현재 컴퓨터에서는 qwen3:8b로 샘플 요약·정답 및 해설이 있는 퀴즈와 출처 조회를 확인했습니다. 상세 결과는 검증기록.txt를 참조하세요.

## 현재 한계와 다음 개선

- 검색은 어휘 기반입니다. 같은 의미의 다른 단어나 한국어 표현을 놓치거나 우연히 겹친 단어를 검색할 수 있습니다. 벡터 검색과 재순위화는 다음 개선 후보입니다.
- AI 핵심 요약은 선택한 자료의 모든 구간을 순서대로 작은 부분에 나눠 읽고 통합합니다. 각 부분의 출처를 원문 ID로 연결하고, 통합 초안을 관련 원문과 다시 대조하도록 모델에 요청합니다. 최종 답변에서 실제 인용한 원문만 표시하며 4개를 넘는 출처는 펼쳐서 볼 수 있습니다. 대조는 모델 기반 검토로, 사실성을 자동 보증하는 검사는 아닙니다. 요약 과정의 세부 내용 생략이나 모델의 사실 오류까지 방지하는 것은 아닙니다. 원문 발췌 모드와 퀴즈·광범위 질문은 기존의 최대 12개 구간 선택 방식을 사용합니다.
- 전체 요약은 호출 수가 늘어 처음 실행이 더 느립니다. 부분별 완료 상태를 화면에 표시하며, 성공한 부분 요약은 SQLite에 캐시해 같은 모델·자료로 다시 요약할 때 재사용합니다. 자료 삭제 후에도 기존 대화와 캐시의 파생 텍스트는 남을 수 있습니다.
- PDF 200페이지/10MB, 추출 텍스트 100만 자 이하. 이미지·표·수식 의미 해석, 스캔 OCR은 제공하지 않습니다. PDF 페이지는 책 인쇄 쪽수와 다를 수 있고 추출 행은 PDF의 시각적 행과 다를 수 있습니다.
- 원문 발췌 모드의 복습 질문은 개방형 원문 설명 연습입니다. AI 정답 생성과 자동 채점은 제공하지 않습니다.
- 현재 대화는 자료 선택 조합별로 구분합니다. 다른 조합을 선택하면 별도 맥락으로 처리합니다. 동일 세션의 요청은 순서대로 처리합니다.
- 자료와 대화는 `data/review.db`에 로컬 저장합니다. 자료 삭제 시 자료·검색 구간은 삭제되지만 이전 대화 기록에 이미 포함된 발췌문은 남습니다.
- 인증 없는 개인용 로컬 앱이므로 기본 주소를 127.0.0.1로 제한합니다. 공개 배포용 인증·사용자별 격리는 미구현입니다.
- 제공 원본에 포함된 LangSmith/MCP 기능을 현재 앱에서 연결했다고 주장하지 않습니다. LangGraph의 추적 환경 설정을 사용하면 자료가 추적 서비스로 전달될 수 있으므로 기본은 끕니다.

## 발표 설명 순서

문제: 흩어진 녹취록과 교안을 다시 찾는 데 시간이 든다.
해결: 자료를 등록하고 질문하면 관련 구간과 위치를 함께 제공한다.
시연: 자료 등록 → 요약 → 질문 → 출처 원문 → 퀴즈 → 새로고침 후 기록 확인.
기술: FastAPI, LangGraph 조건 분기·재시도 상한, 검색 증강, SQLite, 모델 의존성 분리, 자동 테스트.
한계: 어휘 검색, 부분 요약, 인용 형식 검사만으로 사실성 보장 불가.
Before/After 검색 정확도나 사실성 점수는 아직 측정하지 않았습니다. 전체 요약에서 처리한 구간 수·소요 시간·캐시 사용 여부는 scripts/check_full_summary.py로 측정할 수 있습니다. 처리 범위가 늘어났다는 사실을 검색 정확도나 사실성 향상 수치로 해석하지 않습니다. 측정하지 않은 결과를 보고서에 넣지 않습니다.

### 모델 오류 안내

연결 불가, 응답 대기 시간 초과, 잘못된 JSON/출력 길이 초과를 구분해 표시합니다. `LLM_TIMEOUT_SECONDS`로 대기 시간을 조정할 수 있으며 `.env.example`의 값은 180초입니다. 설정 변경 후 앱을 재시작합니다. 모델 서버가 켜져 있어도 긴 자료·모델 로딩·응답 형식 문제로 요청이 실패할 수 있습니다.

### 전체 자료 요약 확인

로컬 Ollama가 실행된 상태에서 `.venv/bin/python scripts/check_full_summary.py`로 등록된 Vector DB 코드 교안의 개선 전후 처리 범위와 시간, 원문 인용을 확인합니다. 결과는 `data/summary_comparison.json`에 저장합니다. 자료·모델에 따라 결과와 시간은 달라집니다.

### OpenAI 실제 API 검증

프로젝트 `.env`에 `OPENAI_API_KEY`를 직접 입력하고 저장한 뒤 실행합니다.

```bash
.venv/bin/python scripts/check_openai.py
```

이 명령은 실제 유료 API를 사용합니다. 포함된 직접 작성 샘플로 질문·퀴즈·분할 요약·원문 대조·출처 조회를 검사하며 결과를 `data/openai_check.json`에 저장합니다. 키를 출력하지 않고 임시 DB를 사용하므로 기존 수업 자료와 대화는 건드리지 않습니다. 실행 중인 앱의 백엔드 설정도 바꾸지 않습니다. 키가 없으면 외부 요청 전에 종료합니다. 모의 테스트 통과와 실제 API 검증 통과를 구분하며, 실제 검증 결과 파일이 없으면 완료로 간주하지 않습니다.
