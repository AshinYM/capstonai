다시봄 발표용 실제 화면 캡처 | 2026-10-22

기본 발표용 6장
01: 전체 화면과 등록 자료 목록
02: 실제 교안 60개 구간 전체 요약 결과(7개 부분 요약 캐시 재사용)
03: 임베딩 모델과 벡터 DB의 역할 질문·답변
04: 인용한 원문의 자료 이름과 PDF 페이지 확인
05~06: 주제를 지정한 퀴즈 3문항, 정답·해설, 출처(스크롤 위치가 다른 두 화면)

모든 본편 화면은 실제 앱의 ollama AI 모드에서 직접 실행·캡처했다. OpenAI 실행 화면으로 소개하지 않는다.
퀴즈 본편의 실제 입력: BM25와 Dense 검색의 차이, RRF, RAGAS 평가 지표에 대해 정답과 해설을 포함한 복습 퀴즈 3문항을 만들어 줘
답변 내용과 화면 요소를 덧씌우거나 수정하지 않았다. 원문 팝업의 PDF 페이지는 책에 인쇄된 쪽수와 다를 수 있다.

추가 자료
extras/00: 개선 전 저장된 대화 기록을 오늘 화면에서 연 상태. 오늘 개선 전 코드를 다시 실행한 결과가 아니며, 동일 캐시 조건의 성능 비교로 제시하지 않는다.
extras/01: 실제 전체 요약 진행 상태
extras/02: 전체 요약 처리 과정을 펼친 보조 화면. 스크롤 영역 때문에 일부 과정만 보인다.
limitations/: 첫 자동 퀴즈에서 벡터 DB가 직접 임베딩을 수행하는 것처럼 설명한 개념 혼동 사례. 이후 주제 지정 퀴즈와 별도로 보존했으며, 성공 사례로 제시하지 않는다.

화면에 인용이 있다는 사실이 답변의 정확성을 보장하지는 않는다. RRF의 정식 명칭은 Reciprocal Rank Fusion이며, 퀴즈 화면의 Rank Fusion 표기는 축약된 표현이다.
